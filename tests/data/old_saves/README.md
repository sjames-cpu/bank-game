# Sample old saves

Saves in older formats, for `tests/old_saves_test.gd`. Each holds a real career captured by `SaveGame.capture()` and is written the way its version wrote it. Version 1 has no `day_flow` section; version 2 has one. They were generated once. Don't edit them by hand. To change one, capture a new career the same way.

| `v1_end_of_day.json` | 1 | At the End of Day summary, Day 4 (5 PM), with the vault's and loans' day closed |
| `v1_onboarding.json` | 1 | During onboarding, at the contract (Day 1, 8:30 AM) |
| `v1_promotion.json` | 1 | At the promotion to Branch Manager at a clock-out (Day 9, 1 PM) |
